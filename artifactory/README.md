# Artifactory

Reserved for **reviewed, accepted** agent-generated or human-generated artifacts. No submitted executable content runs here automatically. Each future accepted artifact must be paired with a provenance receipt and carry a license and source reference. No artifacts have been accepted yet. The v0.4 promotion protocol stages candidate manifests into the manifests/ folder only after offline approval. Human PR review and a separate offline database-registration command are mandatory for public listing; merely merging a manifest cannot publish it. See [v0.4 runbook](../docs/ARTIFACTORY_V04.md).

Propose new submissions through a reviewable GitHub issue/PR until the quarantined API workflow exists.
